# Text Adventure Game

## Project Description

A command-line adventure game developed using Prolog.
Players explore a mansion, collect items, unlock doors,
encounter hazards, and attempt to escape.

## Technologies Used

- Prolog
- SWI-Prolog
- Visual Studio Code
- Git and GitHub

## Features

- Room exploration
- Item collection
- Inventory management
- Locked-door mechanism
- Hazard detection
- Win and lose conditions

## How to Run

1. Install SWI-Prolog.
2. Open the project folder in the terminal.
3. Run:

   swipl adventure.pl

4. Start the game by entering:

   start.
